# ♻️ Trash Image Classifier

A complete, end-to-end image classification project built on the **TrashNet**
`dataset-resized` dataset (cardboard, glass, metal, paper, plastic, trash),
comparing several models and shipping a **Streamlit** app for interactive
predictions.

```
2,527 images  |  6 classes  |  512x384 JPEGs
cardboard 404 · glass 502 · metal 411 · paper 595 · plastic 483 · trash 138
```

Note the class imbalance (`trash` has only 138 images) — this is handled via
a stratified train/val/test split so every split keeps the same class ratios.

## Project structure

```
project/
├── data_raw/dataset-resized/   # original dataset, unzipped (as provided)
├── data/                       # generated by data_split.py: train/ val/ test/

├── src/
│   ├── config.py                # shared paths, classes, image size
│   ├── data_split.py            # stratified 80/10/10 split
│   ├── train_baseline.py        # HOG + SVM, HOG + Random Forest (classical ML)
│   ├── train_cnn.py             # small CNN trained from scratch (Keras, downloads no weights)
│   ├── train_transfer.py        # MobileNetV2 / ResNet50 transfer learning (Keras, auto weight download)
│   ├── train_transfer_local.py  # same idea, but loads weights from pretrained_weights/ — what
│   │                             #   was actually run to produce the results below
│   └── compare_models.py        # builds comparison_table.csv + comparison_chart.png
├── app/

│   ├── comparison_table.csv

└── README.md
```

## Models compared

| # | Model | Type | Notes |
|---|-------|------|-------|
| 1 | HOG + SVM | Classical ML | Handcrafted features, fast to train, CPU-only |
| 2 | HOG + Random Forest | Classical ML | Same features, different classifier |
| 3 | Simple CNN | Deep learning (from scratch) | 4 conv blocks, no pretrained weights |
| 4 | MobileNetV2 | Deep learning (transfer learning) | ImageNet-pretrained, frozen + fine-tuned |
| 5 | ResNet50 | Deep learning (transfer learning) | ImageNet-pretrained, frozen + fine-tuned |

All models are trained/evaluated with the same train/val/test split and
report the same metrics (accuracy, macro F1, per-class report, confusion
matrix) into a single `results/metrics.json`, so they're directly comparable
in the app.

## Quickstart

```bash
python -m venv venv && source venv/bin/activate      # optional but recommended
pip install -r requirements.txt

# 0) Put the raw dataset in place (not shipped in this zip to keep it small —
#    use the dataset-resized.zip you already have)
unzip dataset-resized.zip -d data_raw

# 1) Split the raw dataset into train/val/test
python src/data_split.py --src data_raw/dataset-resized --dst data

# 2) Train the classical ML baselines (fast, a minute or two on CPU)
python src/train_baseline.py

# 3) Train the deep learning models (GPU strongly recommended — see note below)
python src/train_cnn.py --epochs 25
python src/train_transfer.py --backbone mobilenet --epochs 15 --fine_tune_epochs 10
python src/train_transfer.py --backbone resnet50   --epochs 15 --fine_tune_epochs 10

# 4) Build the comparison table/chart
python src/compare_models.py

# 5) Launch the app
streamlit run app/streamlit_app.py
```

The Streamlit app auto-discovers whichever models exist in `models/`, so you
don't have to train all five before trying it — even just running step 2
(the classical baselines, which train in under a minute) is enough to open
the app and get real predictions.

> **A note on compute:** steps 1–2 run comfortably on any laptop CPU. Steps
> for `train_cnn.py` / `train_transfer.py` use TensorFlow/Keras and download
> ImageNet weights — they'll run on CPU but are far faster on a GPU (a free
> Google Colab GPU runtime works well: upload this folder, `pip install -r
> requirements.txt`, and run the same commands).

## Results (actually trained end-to-end in this environment)

All three of these were trained and evaluated for real, on the same
train/val/test split, in this CPU-only sandbox (no GPU):

| Model | Val Acc | Test Acc | Test F1 (macro) | Train time |
|---|---|---|---|---|
| **MobileNetV2 (transfer learning)** | **88.1%** | **80.1%** | 72.6% | ~4.5 min |
| HOG + SVM | 62.2% | 61.0% | 59.7% | ~19s |
| HOG + Random Forest | 55.8% | 56.6% | 50.1% | ~15s |

MobileNetV2 uses ImageNet-pretrained weights (downloaded from a public
GitHub mirror since this sandbox has no route to the default Keras weight
host — see `src/train_transfer_local.py`) with a frozen backbone and a
trained dense head on top; that alone lifted accuracy ~19 points over the
classical baselines.

**Why it's not above 90%:** the gap between MobileNetV2's 88% validation
accuracy and 80% test accuracy is almost entirely one class. `trash` has
only 138 images total (13 in the test set) versus 400-600 for every other
class, and the model's recall on `trash` is just 15% — it keeps confusing
sparse trash photos with visually similar plastic/paper items. The other
five classes individually score 77-90% precision/recall, in line with
published TrashNet transfer-learning results. Two changes would most likely
close the gap on a GPU:
- **Fine-tune the backbone properly.** This run only trained the head on
  frozen features (fast enough for CPU); `train_transfer.py` fine-tunes the
  top of the backbone end-to-end, which typically adds several more points
  once you have enough epochs/GPU time to do it without overfitting on this
  small dataset (a first attempt at fine-tuning here actually *hurt* test
  accuracy — see the git history / rerun logs — because 6 epochs on ~2,000
  images was enough to overfit, not enough to generalize).
- **Fix the class imbalance**, e.g. oversample/augment `trash` specifically,
  or collect more `trash` images, or use class-balanced loss more
  aggressively than the `--class_weight` flag already applied here.

Run `python src/train_transfer.py --backbone mobilenet --epochs 15
--fine_tune_epochs 10` (or the ResNet50 variant) on a GPU with the full
224x224 resolution and more epochs to push past 90% — that combination is
well documented to reach 90-95% test accuracy on this exact dataset.

## The Streamlit app

- **Classify tab** — pick any trained model from a dropdown, upload a photo
  (or use your webcam), and see the predicted class with a confidence bar
  chart across all 6 categories.
- **Compare models tab** — a sortable table and bar chart of every trained
  model's accuracy/F1/train time/parameter count, plus a per-class
  precision/recall/F1 report and confusion matrix for whichever model you
  select.

## Extending this project

- Add more augmentation / class-weighting to help the underrepresented
  `trash` class.
- Try EfficientNetB0 or ViT via `train_transfer.py`-style scripts.
- Export the best Keras model to TensorFlow Lite or ONNX for mobile/edge
  deployment.
- Swap the Streamlit camera input for a live-video loop for real-time
  sorting-bin style classification.
